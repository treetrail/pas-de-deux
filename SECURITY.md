# Security Policy

## Supported versions

Security fixes are made for the **latest version in the App Store and on Google Play**. Please
check that the issue still exists there before reporting it.

## Reporting a vulnerability

**Please do not open a public issue, discussion or pull request for security problems.**

Report vulnerabilities privately via GitHub: open the **Security** tab of
[treetrail/pas-de-deux](https://github.com/treetrail/pas-de-deux) and click **Report a
vulnerability** (`https://github.com/treetrail/pas-de-deux/security/advisories/new`).

Please include:

- the app version and platform (iOS or Android, with OS version),
- a description of the issue and its impact,
- steps to reproduce it,
- a suggested fix, if you have one.

Pas de deux has no server and no accounts. Names, ratings and settings stay on the device. Reports
about data leaving the device, about the consent dialog or about the purchase "Werbefrei" are in
scope.

## What happens next

Your report is only visible to you and the maintainers. We will acknowledge it, investigate, and
keep you updated in the advisory. Once a fix is released, the advisory is published, crediting you
unless you prefer to stay anonymous.

Pas de deux is maintained on a best-effort basis, so please allow some time for a response.
